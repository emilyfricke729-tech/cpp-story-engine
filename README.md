# 🎮 Interactive C++ Story Engine

Eine in C++ entwickelte interaktive Text-Adventure-Engine mit dynamischem SFML-Rendering, Verzweigungslogik, Live-Stats (Stress, Trauma, Selbstwert) und externer Story-Parser-Architektur.

## 🌟 Highlights
- **Data-Driven Architecture:** Dynamisches Einlesen von Story-Nodes und Entscheidungen aus externer `story.txt`.
- **SFML Integration:** Grauer/Farblicher Verlaufshintergrund, Typewriter-Effekt, Journal-Overlay und In-Game-HUD.
- **Bilingual:** Unterstützt Deutsch und Englisch.

## 🛠️ Tech Stack & Requirements
- **Sprache:** C++17 / C++20
- **Framework:** SFML 3.x
- **Build:** Visual Studio / GCC / Clang

## 🚀 Ausführen
1. C++ Compiler & SFML installieren.
2. `main.cpp` zusammen mit der SFML-Bibliothek kompilieren.
3. Sicherstellen, dass `story.txt` und `arial.ttf` im gleichen Ordner liegen.
